About This System

Enterprise Ransomware Risk Assessment System — v{{ APP_VERSION }}

🎯 Project Objective

This web application helps security administrators identify, assess, score, and track ransomware-related risks using a structured risk management process aligned to the NIST Cybersecurity Framework (CSF) 2.0.

It is a defensive cybersecurity tool. It does not create, deploy, or simulate ransomware. It does not encrypt files or interact with real systems outside its own SQLite database.

⚠️ Important Disclaimer

  • This tool is for educational and planning purposes only.
  • It does not detect active ransomware infections in real time.
  • It does not guarantee organisational compliance with NIST CSF or any regulation.
  • Pre-loaded sample records are fictional illustrative assessments — not findings from a real organisation.
  • Always consult qualified cybersecurity professionals for actual security assessments.

📐 Risk Scoring Methodology

Risk scores are calculated using a standard qualitative matrix:

Risk Score = Likelihood (1–5) × Impact (1–5)
Score RangeRisk LevelColour
1 – 4LowGreen
5 – 9MediumYellow
10 – 16HighOrange
17 – 25CriticalRed

🗺️ NIST CSF 2.0 Framework

The NIST Cybersecurity Framework 2.0 organises cybersecurity activities into six core functions:

GV Govern
ID Identify
PR Protect
DE Detect
RS Respond
RC Recover

Each risk is mapped to the most relevant function and category. Refer to nist.gov/cyberframework for the authoritative reference.

🛠️ Technology Stack

  • Backend: Python 3.x, Flask
  • Database: SQLite 3
  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Charts: Chart.js 4
  • Framework: NIST Cybersecurity Framework 2.0

🚀 Key Features

  • Interactive dashboard with live risk statistics and charts
  • Risk register with search, filter, and full CRUD operations
  • Automatic risk score calculation (Likelihood × Impact)
  • NIST CSF 2.0 mapping for every risk record
  • Mitigation tracking with status updates
  • CSV export and printable reports
  • 12 pre-loaded illustrative ransomware risk scenarios
